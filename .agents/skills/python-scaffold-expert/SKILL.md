# Python Scaffold Expert Skill

This skill provides step-by-step guidance for an AI agent to generate, extend, or troubleshoot Python projects generated by `python-universal-scaffold`.

## Core Archetypes Reference

1. **`api-service`**: FastAPI + Uvicorn + Pydantic v2. Optional async PostgreSQL (`SQLAlchemy` + `asyncpg` + `Alembic`).
2. **`data-analytics`**: Polars + DuckDB + PyArrow + JupyterLab + Altair. Includes standard folder `data/` and `notebooks/`.
3. **`ai-ml`**: PyTorch (CPU or CUDA-12) + HuggingFace Hub + NumPy 2.0. Modular scripts `inference.py` and `training/train.py`.
4. **`pipeline-worker`**: Async task consumer with Redis, Structlog, Tenacity, and Pydantic-Settings.
5. **`cli-tool`**: Rich & Typer interactive terminal command application.
6. **`library-package`**: Reusable distribution package targeting wheel/sdist via Hatchling with zero runtime bloat.

## Scaffolding Procedures

### 1. Generating a New Project Locally

```bash
# Basic interactive prompt
uvx copier copy /path/to/python-universal-scaffold my-service

# Non-interactive / headless generation (useful for CI and agent automation)
uvx copier copy \
  --data project_name="order-service" \
  --data package_name="order_service" \
  --data project_archetype="api-service" \
  --data python_version="3.12" \
  --data include_container=true \
  --data include_database=true \
  /path/to/python-universal-scaffold order-service
```

### 2. Post-Generation Initialization

```bash
cd order-service
# Trust mise configuration
mise trust

# Setup virtual environment, copy .env from .env.example, and sync uv lockfile
task setup

# Validate all quality gates
task check:all
```

## Adding New Features to Template

When the user asks to add a new library or tool to the template:

1. **Decide Scope**:
   - Is it universal (applies to all archetypes)? Put in `pyproject.toml.jinja` common section.
   - Is it archetype-specific? Wrap in `{% if project_archetype == '...' %} ... {% endif %}`.
2. **Update `Taskfile.yml.jinja`**:
   - Always route tool execution through `uv run <tool>`.
   - Never run tools against global system python.
3. **Update `copier.yml`**:
   - If user choice is needed, add boolean/choice parameter with helpful prompt and default value.
4. **Smoke Test**:
   - Render a temporary test instance to `/tmp/test-project` and run `task check:all`.
